# Fashion Sales Analysis Project

## About the Project
In this project, I used Python to analyze 5,000 simulated fashion sales records from 2024 to 2025. I wanted to find out which products sell well and how sales change over time.

## Tools I Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## What I Did
- Cleaned the dataset
- Created new columns for sales calculations
- Made 10 charts
- Wrote 5 business recommendations

## What I Found
- Clothing brought in the most revenue.
- Online sales made more money than physical stores.
- Running Sneakers generated the highest product revenue.

## Conclusion
This project helped me understand how to use data to make better business decisions.
