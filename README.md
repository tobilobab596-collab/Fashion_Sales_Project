# Fashion Sales Analysis Project

## About
I used Python to analyze 5,000 simulated fashion sales records from 2024 to 2025.

## Tools
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## What I Did
- Cleaned the data
- Created new columns
- Made 10 charts
- Provided 5 business recommendations

## Key Findings
- Clothing generated the highest revenue.
- Online sales performed better than physical stores.
- Running Sneakers generated the highest product revenue.

## Conclusion
This project helped me learn how to analyze data and make better business decisions.
